# Электронная библиотека

Консольное приложение на C++ для управления библиотечным фондом и учётом выдачи книг читателям.

## Возможности

- Просмотр списка всех книг.
- Добавление и удаление книг.
- Поиск книг по названию.
- Добавление и просмотр читателей.
- Выдача книг читателям.
- Регистрация возврата книг.
- Просмотр истории выдач и возвратов.

## Используемые технологии

- **C++17** — язык программирования.
- **SQLite** — хранение данных.
- **CMake** — сборка проекта.
- **CLion** — среда разработки.

## Структура проекта

- `main.cpp` — главное меню и запуск приложения.
- `models/` — модели книг, читателей и выдач.
- `services/` — логика работы библиотеки.
- `storage/` — работа с базой данных SQLite.
- `CMakeLists.txt` — настройки сборки проекта.

## Запуск

1. Открыть проект в CLion.
2. Убедиться, что установлена библиотека SQLite3.
3. Собрать проект средствами CMake.
4. Запустить приложение.

При первом запуске приложение создаёт или открывает базу данных `library.db`.
